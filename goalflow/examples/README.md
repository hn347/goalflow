# Sample workflow artifacts

These files illustrate a GoalFlow run for a Carbon-styled status dashboard. Read them in order: [goal](sample-goal.md), [discovery](sample-discovery.md), [specification](sample-spec.md), [verification](sample-verification.md), [judge verdict](sample-judge.json), and [summary](sample-final-summary.md).

The application and raw test logs are not included. Treat the passing results and scores as examples of the artifact format, not independently reproducible test evidence. For a real run, replace them with observed results from the target repository and use the current [judge template](../../.bob/templates/judge.json), including failed criteria and any required next actions.
