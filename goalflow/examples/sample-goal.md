# Goal

## Original request

Build an IBM Carbon-styled status dashboard.

## In scope

- Add a dashboard page using Carbon components.
- Display service status, owner, and last updated fields.
- Include accessible empty and loading states.

## Out of scope

- Real production monitoring integrations.
- Authentication changes.

## Acceptance criteria

- Dashboard uses Carbon guidance and tokens.
- UI renders without console errors.
- Tests or smoke checks cover the new route.

## Constraints

- Do not commit MCP credentials.
- Keep implementation minimal.

## Required verification

- Run targeted tests.
- Run build or typecheck.
- Perform browser validation.
