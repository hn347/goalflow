# Demo Script

1. Open the repository in Bob IDE.
2. Install or enable Carbon MCP, Context7 MCP, and Exa MCP without committing credentials.
3. Run `/goal "Build an IBM Carbon-styled status dashboard"`.
4. Show `.goal/goal.md` and `.goal/spec.md` as the contract.
5. Show discovery summaries from repo, docs, and Carbon guidance.
6. Switch to Builder mode for visible implementation.
7. Switch to QA mode and run tests, build, and browser validation.
8. Invoke the independent judge.
9. Show `.goal/judge.json` deciding `complete`, `repeat`, or `halt`.
